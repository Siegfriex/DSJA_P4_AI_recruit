# Governance, RACI & Change Control

## Final authority
User is final approver for major scope, network crawl, model/reference policy and article publication.

## Change control
Patch: metadata only.
Minor: compatible schema/feature/sidecar.
Major: denominator/population/taxonomy semantics/dedup/mapping main rule/model retraining.

Major requires:
impact analysis → reproducible rerun → evaluation → user approval → new release manifest.

## No silent promotion
Code exists ≠ executed.
Test PASS ≠ production quality.
Observed replay ≠ production release.
Structural QA ≠ semantic QA.
