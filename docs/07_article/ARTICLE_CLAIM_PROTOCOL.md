# Article Claim Protocol

## Claim types
DESCRIPTIVE / COMPARATIVE / CONTEXTUAL / QUALITATIVE.

## Status
DRAFT / EVIDENCE_LINKED / VERIFIED / RETIRED.

## Evidence roles
PRIMARY / CONTEXT / EXAMPLE / COUNTERARGUMENT.

Quantitative DESCRIPTIVE/COMPARATIVE claim requires ResultManifest.
Context/interview may not substitute for missing primary result.

Forbidden default claim:
“AI 때문에 ...”

Required trace:
CLAIM → RESULT → MART → FACT/MAPPING → SOURCE EVIDENCE.
